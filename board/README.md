# Доска занятий «Просто 5»

Сайт связывает комнату с уроком, а доска использует сессию личного кабинета. Раздел работает на основном домене по пути /board/. Отдельная пробная доска может продолжать обслуживаться своим процессом и хранить данные в своей папке.

## Сборка

В board/frontend выполните `pnpm install --frozen-lockfile`, затем `pnpm exec vite build --base=/board/` и `node copy-assets.mjs`. Результат находится в board/frontend/dist. Для отдельной пробной доски используйте базовый путь / и точку входа board.standalone:app.

## Включение на сервере

1. Сделайте резервную копию базы и данных действующей доски. Примените sql/lesson_boards.sql от пользователя MySQL с правами на создание таблицы и GRANT.
2. Разместите сборку в отдельной папке, доступной пользователю службы сайта. Задайте переменные в .env сайта:

   ```ini
   LESSON_BOARD_ENABLED=true
   LESSON_BOARD_ORIGIN=https://prosto5.ru
   LESSON_BOARD_DIST=/srv/petrmath/board-dist
   LESSON_BOARD_DATA_DIR=/srv/petrmath/shared/lesson-boards
   ```

   Укажите постоянную папку с правом записи для службы. Данные не должны храниться в каталоге релиза или среди публичных файлов.
3. Проверьте, что Nginx передаёт WebSocket в тот же процесс сайта. Если общий location уже поддерживает Upgrade, отдельный блок не нужен. Иначе в действующий HTTPS server добавьте блок, сохранив настройки вашего upstream:

   ```nginx
   location /board/ws/ {
       proxy_pass http://127.0.0.1:8000;
       proxy_http_version 1.1;
       proxy_set_header Host $host;
       proxy_set_header X-Forwarded-Proto $scheme;
       proxy_set_header Upgrade $http_upgrade;
       proxy_set_header Connection "upgrade";
       proxy_read_timeout 3600s;
   }
   ```

   Используйте фактический адрес процесса сайта. Проверьте конфигурацию командой `nginx -t`, затем перечитайте её и перезапустите службу сайта. Для доски требуется один ASGI-процесс на хранилище, поскольку открытые соединения и блокировки комнат находятся в памяти.
4. Проверьте урок с двумя реальными сессиями и скачивание вложения. Чтобы временно скрыть интеграцию, задайте LESSON_BOARD_ENABLED=false и перезапустите сайт.

Кнопка появляется за 30 минут до начала. Завершённая доска ученику доступна для просмотра. Администратор прикрепляет PDF после отметки «Проведено». Используются обычные вложения конспекта и их действующие ограничения. Старые комнаты отдельной пробной доски не переносятся автоматически.

## Доступ и срок хранения доски занятия

Блок «Предстоящее занятие» находится над расписанием в обоих кабинетах. Кнопка открывается автоматически за **30 минут**; возврат во вкладку перепроверяет доступ. После «Проведено» ученик только просматривает доску, администратор сохраняет право редактирования. «Видеосвязь · Скоро» — неактивная заглушка.

24 часа отсчитываются от отметки «Проведено», а не от открытия доски или загрузки PDF. Старые завершённые доски без записанной даты получают полные 24 часа с первого обнаружения после обновления. Существующие комнаты отдельного пилота на board.prosto5.ru эта очистка не затрагивает.

«Прикрепить PDF к занятию» теперь выполняет экспорт на сервере и сохраняет отпечаток всех листов. Фоновая очистка проверяет этот отпечаток, запись вложения, наличие файла и его контрольную сумму. Если подходящего PDF нет или доска изменялась, сначала создаётся новый PDF всех листов. Обычный загруженный вручную PDF без такого отпечатка не считается подтверждённой копией доски.

На время экспорта изменения доски приостанавливаются. PDF сохраняется в конспекте занятия. Старые версии PDF автоматически не удаляются. После сохранения и проверки удаляются все листы этой доски и их картинки; остаются PDF, запись урока и небольшой служебный маркер, запрещающий повторное создание по старой ссылке. Удаление не использует общую очистку материалов/Google Диска.

При ошибке экспорта, нехватке места, превышении 10 МБ для PDF или лимита 5 вложений доска остаётся. В кабинете администратора отображается предупреждение; повторная попытка — через 15 минут. Очистка проверяет сроки раз в минуту. Большие доски (более 32 МБ данных для экспорта) также остаются для ручного разбора, чтобы экспорт не исчерпал память сервера.

## Обновление действующего сервера

Код и Python-зависимость Playwright попадут через обычный deploy. Миграция SQL для этой правки **не нужна**. Сборка интерфейса доски размещается отдельно, как раньше.

1. Соберите `board/frontend` по инструкции выше и перенесите архив сборки с Mac:

   ```sh
   scp /private/tmp/prosto5-lesson-board-assets.tar.gz root@178.212.14.19:/root/
   ```

   После успешного deploy выполните **на сервере**:

   ```sh
   mkdir -p /srv/petrmath/board-dist
   tar -xzf /root/prosto5-lesson-board-assets.tar.gz -C /srv/petrmath/board-dist
   test -f /srv/petrmath/board-dist/export.html
   cd /srv/petrmath/app
   .venv/bin/python -m playwright install-deps chromium
   install -d -o petrmath -g petrmath -m 750 /srv/petrmath/shared/playwright
   runuser -u petrmath -- env PLAYWRIGHT_BROWSERS_PATH=/srv/petrmath/shared/playwright \
     /srv/petrmath/app/.venv/bin/python -m playwright install chromium --only-shell
   ```

2. В `.env` сайта добавьте путь браузера. Автоудаление при первой проверке оставьте выключенным:

   ```ini
   PLAYWRIGHT_BROWSERS_PATH=/srv/petrmath/shared/playwright
   LESSON_BOARD_RENDER_PORT=8000
   LESSON_BOARD_CLEANUP_ENABLED=false
   ```

   Экспорт обращается к loopback-порту процесса сайта, не к внешнему домену; при другом порте измените `LESSON_BOARD_RENDER_PORT`. В Nginx у основного `location /`, проксирующего на сайт, задайте `proxy_read_timeout 360s;`, затем проверьте `nginx -t` и выполните `systemctl reload nginx`.

3. Перезапустите `systemctl restart petrmath`, обновите вкладки и на тестовом проведённом уроке нажмите «Прикрепить PDF к занятию». Проверьте все листы PDF и скачивание учеником из конспекта.

4. Только после этой проверки замените значение `LESSON_BOARD_CLEANUP_ENABLED` на `true` и перезапустите `petrmath`. Включение разрешает удаление подходящих досок, для которых уже истекли сутки. До истечения срока даты можно увидеть в карточке проведённого урока. Если режим выключен, автоматического удаления нет.

Журнал: `journalctl -u petrmath --since today --no-pager`. Ошибки отмечаются `lesson_board_cleanup_failed`; серверный экспорт — `lesson_board_pdf_failed`. Содержимое урока в эти сообщения не записывается. Сервису по-прежнему нужен **один ASGI-процесс** на папку досок. Перед сменой версии Playwright установите соответствующую ей версию Chromium в ту же постоянную папку; обычные обновления проекта не должны удалять эту папку.

## PDF длинных листов

Экспорт масштабирует каждый лист по ширине A4 (полезная ширина 190 мм), сохраняя один масштаб на всех его страницах. Длинные листы разбиваются сверху вниз, предпочтительно по свободным горизонтальным промежуткам. Большие пустые промежутки между заданиями пропускаются. Отдельные листы доски начинаются с новой страницы PDF; нумерация общая.

Если один рисунок/объект выше страницы и свободной полосы нет, он продолжается на следующей с небольшим перекрытием. Гарантировать смысловую границу внутри такой картинки нельзя. Объекты не удаляются из исходной доски. Предпросмотр и ручные разрывы в этой версии не добавлены.

Каждая страница рендерится отдельно с шириной 2000 пикселей, чтобы длинная доска не теряла разрешение при уменьшении до одного изображения. Используется JPEG высокого качества и сжатие PDF. Предельное число страниц — 120; при превышении экспорт останавливается с сообщением, а автоочистка сохраняет доску.

Общий модуль `frontend/src/lesson-pdf.js` используется и скачиванием, и серверным экспортом для прикрепления/очистки. Версия алгоритма входит в отпечаток PDF: старый PDF не считается актуальной копией нового формата. Сервер также проверяет версию загруженной сборки. При несовпадении он оставляет доску и просит обновить сборку, вместо удаления после экспорта старым алгоритмом.

Для обновления достаточно обычного deploy кода, загрузки новой сборки в `/srv/petrmath/board-dist` и перезапуска `petrmath`. Повторно устанавливать Chromium не нужно, если он уже установлен по инструкции выше. Обновите открытые вкладки. Ранее скачанные PDF не меняются: новый формат появляется при повторном экспорте существующей доски.

Проверка разбиения: `node --test tests/test_board_pdf_layout.mjs` из корня проекта.

## Меню и геометрические заготовки

Верхняя панель разделена на листы (слева), «Фигуры» (в центре), «Сохранить» и «Ещё» (справа). Индикатор заполнения находится возле выбора листа. Кнопка пересылки ссылки убрана: доступ к доске занятия открывается из личного кабинета.

«Фигуры» содержит координатную сетку, личную библиотеку заготовок и 18 подписанных шаблонов по категориям: треугольники, четырёхугольники, окружность, геометрические обозначения и координатные оси. Заготовки вставляются в центр текущего вида как обычные редактируемые векторные объекты; составные рисунки сгруппированы для перемещения целиком. Для изменения отдельных частей можно разгруппировать их штатными средствами доски. Новые фигуры защищены от ластика теми же правилами, что существующие геометрические объекты; явное удаление выделенного объекта остаётся доступным.

Отдельная кнопка библиотеки справа скрыта, личные заготовки открываются из «Фигур». Их постоянное хранение на сервере не добавлено; набор можно сохранять и загружать файлом библиотеки. Стереометрия пока не добавлена.

«Сохранить» содержит PDF всех листов, прикрепление PDF к проведённому занятию (только администратор) и редактируемую копию текущего листа. «Ещё» — отчёт о соединении и очистку текущего листа через существующее подтверждение. Права доступа и правила хранения/удаления досок сохранены.

Меню закрываются по Escape, выбору действия и нажатию снаружи; на узких экранах панель переносится, а выпадающий список прокручивается в пределах экрана. Тесты геометрии: `node --test tests/test_board_geometry.mjs`.

После deploy обновите сборку в `/srv/petrmath/board-dist`, перезапустите `petrmath` и обновите вкладки. Новые зависимости, повторная установка Chromium или миграция базы для меню не нужны.
